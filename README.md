# MT-SLEEP

A private-by-design Arabic (RTL) Android sleep-cycle planner, exact alarm, and experimental overnight sound-event monitor.

## Download on Android

Open [Releases](https://github.com/MohamedTaltlo/sleep-calculator/releases/tag/latest) and download **MT-SLEEP.apk** after the Android APK workflow succeeds. This APK is generated by GitHub Actions. Allow your browser/file-manager to install APKs when prompted. The initial builds use a CI debug certificate; installing a later build may require uninstalling the earlier build (which loses app data). A private release signing key is recommended for reliable in-place updates.

## Simplified nightly flow (v1.1.0)

1. Open the app just before going to bed. The planner **automatically assumes bedtime is now** and adds 15 minutes to fall asleep. No bedtime input or cycle setup is needed.
2. Set only the **desired wake-up time** (e.g. 08:00).
3. Select **before** (end of preceding 90-minute cycle), **exactly** (requested time), or **after** (end of following 90-minute cycle). An estimated best choice is highlighted, and any lateness is clearly shown before arming.
4. Arm the alarm. Ringtone, maths challenge, snore monitor and permissions are under one collapsed **Additional settings** section.

When returning to the app after a long delay the bedtime reference is refreshed, so the recommendation is recalculated. For critical appointments choose the exact or early option.

## Features

- Choose desired wake time (e.g. 08:00). Recommend a cycle boundary (default 90-minute cycles) within a configurable **early** window. Falls back to the strict target time if no boundary fits.
- Take current or chosen bedtime into account, plus sleep-onset latency; show 4/5/6-cycle bedtimes.
- Exact Android alarm clock using AlarmManager.setAlarmClock(); locked-screen alarm with vibration, system ringtone picker, or built-in loud synthesized tone.
- Optional maths challenge to dismiss and a 5-minute snooze.
- Optional local microphone foreground service with basic repeat-burst audio heuristics (NOT sleep staging or medically accurate snore classification). Only summary counts/timing stored, no recordings or audio uploads.
- Re-apply an armed future alarm on reboot/timezone/manual clock change. Android battery optimization and alarm permissions remain device-controlled.
- No Internet permission, no analytics.

## Important limitations

Sleep cycles do not run on an exact fixed 90-minute clock for everyone or every night. **MT-SLEEP does not detect REM, true sleep stages, or actual sleep onset** from a phone microphone. Its suggested wake times are arithmetic estimates. The sound monitor reports *possible* snore-like acoustic events (not a diagnosis); noises from fans, blankets, another person, or traffic may trigger false positives. Loud alarms cannot guarantee waking up; keep a second alarm for essential commitments. If you frequently sleep through extremely loud alarms despite sufficient sleep, consider discussing it with a clinician or sleep specialist.

On Android 14+, microphone monitoring must be started **while the app is visible**; it cannot automatically restart after a reboot. The alarm works without the microphone. To improve reliability, allow **Alarms & reminders**, notifications, full-screen alarms and ignore battery optimization where supported. The system can still restrict apps on vendor-customized Android.

## Build locally

Requires Java 17, Android SDK 35, Gradle 8.11.1.

```sh
gradle :app:assembleDebug
```

Output: `app/build/outputs/apk/debug/app-debug.apk`.

Unit tests: `gradle :app:testDebugUnitTest`.

## Automatic APK

GitHub Actions `.github/workflows/android.yml` builds on push to main or manual workflow dispatch, tests the planner, publishes the APK as workflow artifact, and uploads it to a pre-release under tag `latest`. It does not publish to Google Play.

## Privacy

No network permission. Microphone is opt-in and monitored locally in a foreground service started by a visible user action. It stores only counters/timestamps in app-private SharedPreferences, not raw recordings. Stop monitoring anytime in the app.

## Developer notes

Native Java, minimum Android 8 (API 26), target Android 15 (API 35). Package `online.mtradius.mtsleep`. Permissions requested on demand. No background microphone auto-start.
